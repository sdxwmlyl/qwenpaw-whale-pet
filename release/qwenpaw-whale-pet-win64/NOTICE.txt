## What this project reuses

- Character artwork / state images under `overlay/dist/assets/`
  (derived from the upstream `assets/generated/*.webp` set, file names normalized)
- Character design and animation intent

## What this project adds

- Independent Tauri desktop overlay (transparent, always-on-top, tray, click-through)
- `bridge.py`: QwenPaw state adapter (`/api/chats` → `/state`), tool-name → pose mapping,
  per-turn token / tok/s / cache-hit extraction, and the stats system
- Frontend interaction rules: hover, double-click, idle fidgets, streak, error, night,
  festival triggers, HUD, four window sizes, sticky token notification
