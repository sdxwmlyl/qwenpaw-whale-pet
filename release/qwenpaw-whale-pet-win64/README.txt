QwenPaw Whale Pet · 鲸鱼娘桌宠（免安装版）
=============================================

启动：双击 start.bat（会自动先起状态桥，再起桌宠）
退出：右键桌宠 → 退出

说明
----
- 需要 QwenPaw 桌面版本机运行（默认接口 http://127.0.0.1:64445）
- whale-pet.exe  桌宠本体（含全部素材与音效）
- bridge.exe     状态桥（读 QwenPaw 的会话状态与 token）
- 不需要安装 Python

交互
----
拖动移动 · 单击摸头（连点 3 次害羞）· 双击调戏 · 悬停好奇
右键：投喂 / 摸头 / 睡觉 / 数值 / 声音 / 大小 / 隐藏 / 退出
托盘右键：显示隐藏 / 👻 穿透模式 / 退出
F9 样例 token 通知 · F10 成功音 · F11 提醒音
